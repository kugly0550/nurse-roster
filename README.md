# 간호사 근무표

요일별 근무 인원, 나이트 다음날 off, D 연속 제한 같은 조건을 넣으면 한 달 근무표를 자동으로 만들어 주는 웹페이지.

- 조건을 다 지킬 수 없으면 가장 적게 어긴 안을 만들고, 어긴 곳을 날짜·사람 단위로 보여준다.
- 칸을 눌러 신청(off/D/E/N)하거나 고칠 수 있고, 고친 칸은 다시 만들어도 그대로 남는다.
- 종이 양식(A4 가로, 일요일 대각선) 그대로 이미지로 저장·공유·인쇄한다.
- 데이터는 이 기기의 브라우저에만 저장된다. 백업 파일로 옮길 수 있다.

계산은 [HiGHS](https://highs.dev/)(highs-js, MIT)로 브라우저 안에서 한다. 서버는 없다.
